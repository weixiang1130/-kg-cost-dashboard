# 假設工程結算監控儀表板

## 需要的檔案

```
你的工作資料夾/
├── kg_dashboard.py        ← 主程式（必要）
├── 啟動儀表板.bat          ← 雙擊啟動（必要）
├── kg_data/               ← 放 KG 一覽表（自動建立）
├── kg_snapshots/          ← 歷史快照（自動建立）
└── kg_areas.json          ← 各專案面積（自動建立）
```

你只需要把 `kg_dashboard.py` 和 `啟動儀表板.bat` 這兩個檔案放在同一個資料夾。


## 首次安裝（只需一次）

你的電腦需要有 Python 3.8 以上版本。如果還沒有：
1. 到 https://www.python.org/downloads/ 下載安裝
2. 安裝時勾選「Add Python to PATH」

套件會在首次啟動時自動安裝（streamlit, openpyxl, lxml, plotly, pandas）。


## 啟動方式

**雙擊 `啟動儀表板.bat`**

瀏覽器會自動開啟 http://localhost:8501 。如果沒有自動開啟，手動在瀏覽器輸入這個網址即可。

要停止儀表板，在命令列視窗按 Ctrl+C。


## 使用流程

### 第一步：上傳 KG 一覽表

在儀表板左側欄點「Browse files」，選擇一個或多個 KG 預算發包請款結算一覽表的 .xlsx 檔案。

也可以把檔案直接放進 `kg_data/` 資料夾，然後點「掃描資料夾」。

### 第二步：輸入面積

上傳後畫面會顯示偵測到的專案名稱，以及面積輸入欄位。

- 選擇單位（m² 或 坪）
- 輸入數字
- 面積會自動儲存，下次不用重複輸入

### 第三步：執行分析

點「🚀 執行分析」按鈕。系統會：
1. 用 XML 解析讀取 KG 一覽表（與假設工程分析 v4 邏輯完全一致）
2. 提取 13 個工程項目的預算金額和結算金額
3. 根據面積計算元/坪
4. 自動儲存一份快照到 `kg_snapshots/`
5. 如果有之前的快照，自動比對顯示增減

### 第四步：查看結果

每個專案有三個分頁：
- **📋 分析表** — 預算金額 | 元/坪 | 結算金額 | 元/坪 | 差異 | 趨勢線
- **📈 趨勢追蹤** — 結算總額折線圖 + 各項目趨勢 + 每期增量
- **📊 跨期比較** — 最近兩次讀取的逐項對比


## 趨勢追蹤機制說明

趨勢功能是靠「多次上傳」累積出來的，不是從單一檔案內推算的。

運作方式：

```
第1週（4/14）上傳 KG 表 → 快照 #1：結算 2.41 億
第2週（4/21）上傳 KG 表 → 快照 #2：結算 2.48 億 → 顯示 +700 萬
第3週（4/28）上傳 KG 表 → 快照 #3：結算 2.53 億 → 顯示 +500 萬
第4週（5/05）上傳 KG 表 → 快照 #4：結算 2.61 億 → 顯示 +800 萬
                                                    ↓
                                              趨勢線成形
```

每次你上傳新版本的 KG 一覽表，系統就會多存一份快照。快照儲存在 `kg_snapshots/` 資料夾，是 JSON 格式的純文字檔案，可以手動打開查看或備份。

結算金額理論上只會增加不會下降，所以趨勢線應該是持續向上的。如果某一期金額下降了，表格會標綠色讓你注意。

**建議操作頻率：每週一次**，配合你每週從 KG 系統匯出的一覽表。

## 常見問題

**Q: 面積輸入錯了怎麼辦？**
直接在面積欄修改數字即可，會自動儲存覆蓋。也可以手動編輯 `kg_areas.json`。

**Q: 怎麼刪除錯誤的快照？**
到 `kg_snapshots/` 資料夾刪除對應的 .json 檔案。

**Q: 可以同時看多個專案嗎？**
可以。同時上傳多個 KG 表，會以分頁方式並排顯示，還有跨專案比較圖。

**Q: 支援 .xls 格式嗎？**
目前只支援 .xlsx。如果有 .xls 檔案，請先用 Excel 另存為 .xlsx。
