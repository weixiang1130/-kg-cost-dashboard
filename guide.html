根基營造 KEDGE · 成本監測儀表板 — 地端運行使用指南 · v2.1.0

系統架構

本系統為純地端運行，無需安裝 Node.js，瀏覽器即可操作。

層級技術說明
前端React 18 CDN + Babel瀏覽器內直接編譯 JSX，無需打包
後端FastAPI + UvicornREST API，同時提供靜態檔案服務
資料庫SQLitekg_history.db，單檔即所有資料

快速啟動

首次安裝（僅需一次）

1
確認 Python 已安裝

開啟命令提示字元，輸入以下確認版本（需 3.10 以上）：

python --version
2
安裝 Python 套件

在專案根目錄執行：

pip install -r requirements.txt

主要安裝：fastapi uvicorn openpyxl numpy scipy

每次使用

1
啟動伺服器

方法 A：雙擊 start_api.bat

方法 B：命令列執行

cd "專案資料夾路徑"
uvicorn api_server:app --reload --port 8000
2
開啟瀏覽器

前往 http://localhost:8000

3
結束使用

回到命令提示字元按 Ctrl + C 關閉伺服器

API 文件：啟動後可至 http://localhost:8000/docs 檢視 Swagger 互動式文件。

五大功能頁面

1
總覽儀表板
首頁 — 跨專案快照總覽
  • KPI 卡片：假設工程專案數、造價分析專案數、FAB / CUP 類案件數
  • 類型分佈：依 FAB / CUP / OFFICE / 其他 顯示各類筆數
  • 快速動作：直接跳轉至匯入、分析、預估、歷史頁
2
假設工程分析
上傳 KG 一覽表 → 13 項目結算追蹤
  • 匯入：拖拉或選擇 .xlsx 檔，系統自動解析 B2 專案名稱 + B3 截止日
  • 分析表：13 項假設工程（租工、打石工、技術工…）的預算 vs 結算差異
  • 趨勢追蹤：多期快照結算走勢圖
  • 專案切換：右側快速切換不同專案
3
造價分析
上傳造價 Excel → 八大類工程造價統計
  • 匯入：上傳造價 Excel，系統自動解析八大類（土方/結構、外牆/裝修…）
  • 甜甜圈圖：造價組成占比
  • 柱狀圖：八大類成本排行
  • 下載：匯出分析結果為 Excel
4
投標預估
面積回歸 + What-if 敏感度試算
  • 輸入：選擇類型（FAB / CUP / OFFICE）+ 輸入面積（坪）
  • 預估結果：回歸預估造價 + R² 信心指標 + 95% 信賴區間
  • 回歸散點圖：歷史案例 + 回歸線 + 信賴帶
  • What-if：鋼筋 / 混凝土 / 工資指數滑桿即時調整
  • 同類明細：列出同類型歷史專案的面積、造價、元/坪
5
歷史記錄
跨專案快照管理
  • 切換「假設工程」/「造價分析」tab 瀏覽全部快照
  • 顯示：專案名稱、截止日、類型、結算金額、預算/面積
  • 造價快照可下載原始 Excel
  • 支援逐筆刪除（刪除前會確認）

資料備份與移機

所有專案資料（含原始 Excel 二進位）都儲存在單一檔案：

kg_history.db  ← SQLite 資料庫
kg_areas.json  ← 面積對照表

備份或移機時，只需複製這兩個檔案到新電腦的同一目錄即可。

資安提醒：kg_data/ 內的 Excel 檔案、kg_history.db 資料庫、kg_areas.json 面積表均為公司機敏資料，已在 .gitignore 中排除，不會上傳到 Git。

常見問題

Q: 瀏覽器開啟後白屏？

確認伺服器正在執行（命令視窗應顯示 Uvicorn running on http://127.0.0.1:8000）。若已關閉，重新雙擊 start_api.bat。

Q: 首頁 KPI 全部顯示 0？

資料庫為空。請到「假設工程分析」或「造價分析」頁面上傳第一筆 Excel，上傳後首頁會自動更新。

Q: 上傳 Excel 後顯示「解析失敗」？

確認檔案為 .xlsx 格式（非 .xls 舊格式），且 B2 為專案名稱、B3 為截止日。

Q: port 8000 被佔用？

修改 start_api.bat 中的 --port 8000 為其他埠號（如 8080），並在瀏覽器前往對應網址。

Q: 想移回 Streamlit 舊版？

所有 Streamlit 相關檔案在 _archive/streamlit/ 中，將 kg_dashboard.py 複製回根目錄，雙擊 start_dashboard.bat 即可。
